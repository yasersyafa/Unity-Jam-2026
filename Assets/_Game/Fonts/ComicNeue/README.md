# ComicNeue-Regular

Use `ComicNeue-Regular SDF.asset` in TextMeshPro's Font Asset field.

Static antialiased SDF atlas: 1024 x 1024, sampling size 80, padding 8.
All printable ASCII characters (U+0020–U+007E) are baked. Latin-1 and
common typographic punctuation are included where supported by this font.
Source font, source URL, and license are included in this folder.

Optional characters not baked: none.
No scene, prefab, or global TMP font setting was changed.
